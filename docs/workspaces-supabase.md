# مساحات العمل على Supabase

## المشكلة
كانت المساحات في `localStorage` فقط → لا تتزامن بين الأجهزة/المتصفحات بينما المهام على Supabase.

## الحل
جدول `public.workspaces` + `useWorkspaces` يقرأ/يكتب منه مع:

1. **ترحيل تلقائي** من `mahd_workspaces_v1` عند أول تحميل وجدول فارغ (أو دمج المساحات المحلية الناقصة).
2. **كاش محلي** بعد كل تحميل ناجح (احتياط offline).
3. **المساحة النشطة** تبقى تفضيلاً على الجهاز (`mahd_active_workspace_v1`).
4. **Realtime** على الجدول لمزامنة فورية بين التبويبات/الأجهزة.

## مطلوب منك مرة واحدة
في Supabase → SQL Editor نفّذ:

`supabase/migrations/20260808_workspaces.sql`

بعدها حدّث الصفحة. إن ظهرت مساحاتك المحلية في DB فالنقل نجح.

## الحقول
| عمود | معنى |
|------|------|
| id | نفس `tasks.context` |
| label / icon / color / bg | العرض |
| trait | سمة نصية |
| archived | أرشفة المساحة (لا حذف) |
| sort_order | ترتيب الشريط |
| is_default | عمل / شخصي / علامة |

## ملاحظات أمان
RLS مفتوح لـ anon مثل `tasks` الحالية (مستأجر واحد). عند إضافة Auth لاحقاً يُقيَّد بـ `user_id`.

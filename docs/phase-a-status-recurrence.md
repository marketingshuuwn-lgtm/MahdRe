# الموجة A — حالات + دورية

## الحالات
| status | سلوك |
|--------|------|
| not_started / in_progress / completed | دورة الزر الدائري |
| deferred | تبقى في القاعدة، تُستبعد من المصفوفة النشطة، شارة مؤجلة، إعادة تنشيط من الزر أو إعادة جدولة |
| cancelled | status + archived فوراً → الأرشيف بوسم ملغاة |

## الدورية
- إنجاز الأمس لا يغلق مهمة اليوم (isCompletedToday)
- isTaskOverdue للدورية: حدوثات سابقة ضمن العمر بدون إنجاز اليوم
- أيام العمل من الإعدادات (الجمعة وغيرها) عبر workDays
